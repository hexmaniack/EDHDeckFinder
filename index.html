MTG Deckfinder

Sammlung laden, dann vergleicht die App EDHREC-Average-Decks, Combos von Commander Spellbook und offizielle Precons mit deinen Karten.

1. Sammlung laden

CSV-Export aus Moxfield, Archidekt, ManaBox o. ä. (Spalten „Name“ und „Count/Quantity“) oder eine Textliste mit „1 Sol Ring“ pro Zeile.

Die Datei wird sofort nach der Auswahl geladen.

2. Commander wählen

EDHREC Average Deck
Bracket:
Budget:
Thema:
Varianten überspringen, wenn EDHREC höchstens Decks dafür meldet

Ergebnisse

Combos aus meiner Sammlung

Daten von Commander Spellbook. Die App sucht alle Combos, bei denen du jede Karte besitzt. Nur mit dem lokalen Server verfügbar.

Offizielle Commander-Precons

Daten von MTGJSON. Zeigt, welche Precons du schon ganz oder fast besitzt. Nur mit dem lokalen Server verfügbar.

Einzelnes Deck prüfen

Decklist von einer beliebigen Seite (z. B. Moxfield) einfügen.
